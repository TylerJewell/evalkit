API names carry this vocabulary into the compiler

RunOutcome.isEvidence(), CampaignReport.isTrustworthy(), Grade and Inconclusive put this vocabulary in the compiler. A caller reading isTrustworthy() cannot tell what it checks. hasCompleteResults() names the condition.

Table cells written as fragments

Nineteen cells in the DeepEval comparison tables read as fragments: "Same position.", "Field for field.", "Split in two.", "New work.", "Mechanical.", "Opposite." A cell quoted on its own by a search result carries no subject.

The auditor never saw them. Its element list held p, h1 to h4, figcaption, blockquote, li, dd and caption, and no HTML table cell had been checked since the tool was written. Adding td and th on 8 August 2026 surfaced 88 violations across these documents and 235 across the collateral. Giving each cell a subject and a verb costs four words per row.

What to do with this list

Nine entries name methods, fields or types. Renaming isTrustworthy() and isEvidence() belongs with the breaking changes listed for 0.1.0, because both appear in the published API surface.

Sixteen entries are prose only and cost one edit each.

Six entries are already rejected by tools/audit-prose.py. The rest need either a pattern or a reading pass, and the terms with an existing type name behind them, such as Lanes and wave, stay as they are so the prose matches the code.
